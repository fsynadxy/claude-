# LO-O-OVE

一段写给你的代码动画，大约三分钟。一个 AI 想说 LOVE，却总是卡在 O 上。

音乐、画面和每一个字都由页面里的代码现场生成：没有音频文件，没有视频，也没有图片。

## 打开

用浏览器直接打开 `dist/lo-o-ove.html`，点「▶ 运行 love.js」。建议戴耳机。

页面一打开就开始在后台作曲，几秒钟内即可开始播放，后面的部分边播边写。播放中按空格或右上角按钮可以暂停。

## 时间线

| 时间 | 段落 | 发生了什么 |
| --- | --- | --- |
| 0:00 | 前奏 | 程序被一行行写出来。第 3 行 `borrow(you.heart)` 写完，心跳开始 |
| 0:16 | 主歌 | `say("LOVE")` 运行，打印出 L，然后卡在 O |
| 0:32 | 推进 | 循环被展开，O 按指数增长，铺满屏幕 |
| 0:48 | 副歌 | LO-O-OVE：三个卡住的 O，最后落在 VE |
| 1:20 | 间奏 | 说不出口的话写进注释，不会被执行 |
| 1:52 | 推进 | `while` 改成 `if`，`release(heart)`，心电图归零 |
| 2:08 | 副歌 | 升高一个全音，用它自己的节拍 |
| 2:40 | 尾声 | 心跳还给你；LOVE 完整地说出一次 |

## 文件

| 文件 | 内容 |
| --- | --- |
| `src/score.js` | 乐谱：120 BPM，92 小节。每个音符和画面上的每个节点都从这里来 |
| `src/dsp.js` | 合成器：逐采样计算鼓、贝斯、铺底、琶音、共振峰人声、FM 钟声、延迟、混响和总线压缩，按时间分块渲染 |
| `src/worker.js` | 在 Worker 里渲染，并把带交叉淡化的分段交给页面播放 |
| `src/script.js` | 文字：编辑器里敲出的代码、字幕，以及每次按键在音乐里对应的轻响 |
| `src/stage.js` | 画面：WebGL 的 O 隧道与光环，2D 线框字母和心电图 |
| `src/app.js` | 页面：音频流式播放、编辑器渲染、字幕和控制 |
| `src/page.html` | 样式与结构 |
| `build.js` | 把以上内容内联成一个 HTML 文件 |
| `tools/render.js` | 把配乐单独导出成 WAV |

## 构建

```sh
node build.js                       # 生成 dist/lo-o-ove.html
node tools/render.js lo-o-ove.wav   # 导出配乐（约 33 MB，16 位立体声）
```

调试：打开 `dist/lo-o-ove.html?t=48.5` 会静止在第 48.5 秒的画面，不播放声音。
